# Лиды Братска — рабочая страница

Одностраничное приложение для обзвона: список организаций Братска из 2ГИС, у которых не указан сайт, плюс результаты автопроверки через Brave Search API.

Открывается на телефоне и компьютере по адресу:
**https://urasokolik.github.io/bratsk-leads-app/**

## Что внутри

- 766 организаций, 11 из них с найденным сайтом (скрыты по умолчанию), 210 — с кандидатами на ручную проверку.
- Статус «Сайта нет» ставится только вручную, после галочки подтверждения. Автопроверка такого статуса не ставит никогда.
- Заметки, статусы звонков и согласия хранятся в localStorage браузера, то есть отдельно на каждом устройстве. Экспорт — кнопка «CSV».

## Обновление

Страница собирается из приватного репозитория `urasokolik/bratsk-leads` (`node build.js`), сюда копируется только готовый `index.html`. Исходники и сырые данные 2ГИС в этот репозиторий не попадают.

## Данные

Контакты организаций взяты из открытых карточек 2ГИС и используются для подготовки адресных коммерческих предложений. Это не база для массовых рассылок.
